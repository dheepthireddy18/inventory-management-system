# Changelog

All notable changes to this project are listed here.

## [1.1.0] - 2026-11-02

### Added
- The menu shows a banner with the number of low stock products when it starts.

## [1.0.0] - 2026-11-02

### Added
- SQLite database with five STRICT tables, sample data, and rules enforced by the database.
- Product management, filtered search, and four reports.
- Restock, adjust, and record a sale, each as a single transaction with a stock movement log.
- Terminal menu with friendly error messages, database backup, and a Docker image with the data kept in a volume.
